# 업무 문제 해결 기록

이 폴더는 업무 중 발생한 문제를 **문제 발견 → 원인 분석 → 대안 설계 → 협의 → 적용 → 재발견 → 개선 → 결과**의 과정으로 기록하기 위한 공간입니다.

## 기록 원칙
- 사실과 해석을 구분한다.
- 개인의 잘잘못보다 프로세스와 R&R을 우선 분석한다.
- 제안 내용과 실제 합의/적용 내용을 구분한다.
- 운영 후 발견된 문제와 변경사항을 계속 누적한다.
- 결과가 확인되기 전에는 개선 효과를 임의로 주장하지 않는다.
- 최종적으로 포트폴리오의 **Problem → Action → Iteration → Result**로 재구성할 수 있도록 기록한다.

## 사례
- [Dev Build 중간점검 운영 프로세스 개선](./mid-check-build-operation.md)

## 향후 기록 방식
새로운 업무 문제가 발생하면 주제별 파일을 추가하고, 기존 사례는 동일 파일에 시간순으로 업데이트합니다.
